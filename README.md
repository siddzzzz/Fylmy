# Fylmy

After getting irritated by useless and complex video editors, I decided to make one on my own for simple use. Its cannot serve the professionals but it should certainly be enough for those who want to edit their videos for their small projects of functions etc.

## Features
- **Multi-Aspect Ratio**: 16:9 Landscape, 9:16 Portrait (Shorts/Reels/TikTok), 1:1 Square, 4:5 Social, 21:9 Anamorphic.
- **Multi-Track Timeline**: Dual video tracks (V1, V2), audio tracks (A1, A2), tracking mask track, and title track.
- **Motion Tracking Mask**: Gaussian blur and mosaic pixelate censor that tracks moving subjects across keyframes.
- **Editing Tools**: Razor split tool (`S`), trim handles, clip dragging with magnetic snapping, and zoom.
- **Color Grading & Speed**: Brightness, contrast, saturation, white balance, vignette, and playback rate adjustments.
- **Zero-Watermark Export**: Offline frame-by-frame rendering in 720p, 1080p, and 4K (WebM / MP4).

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.
